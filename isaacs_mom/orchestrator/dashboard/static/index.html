Run

Runs, live first

    Labels

    Live
    Events are arriving (the last within 20 s), or a fine-tune started in the last 30 minutes is still running. Its dot pulses.
    Recorded
    From the run's saved files; nothing new is arriving for it.
    Placeholder
    The run is on FakeSim, the stand-in simulator. A panel with nothing to show says so in words.
    Disconnected
    The page lost the run's event stream and is retrying; nothing shown is live until it returns.
    Paused
    Space is holding the view; new events wait until it resumes.
    Configured
    Set in the code, not measured.
    Not started
    A Teach the task generator refused, a task the loop does not train on yet, or a run that stopped before its first episode. The run says why.
    StudentTeacher
    Who chose a skill: blue for the student, teal for the teacher. Green and red mark only success and failure.

    The header names the run's label; a panel shows its label's dot, and its word only where it differs.

    Results strip

    One column per held-out seed, in seed order; choose one to see that seed's tests. Three rows:

    Status
    How the seed changed from the first checkpoint to the latest, the one row in colour:
    Improved (failed, then succeeded) or regressed (succeeded, then failed)
    Always passed or still fails
    Errored at either, counted apart, never as a failure
    Pending: the latest test hasn't reached the seed, or there is only one
    Before, After
    The seed's verdict before fine-tuning and after the latest round, uncoloured:
    Succeeded, failed, errored, not run yet
    A chosen seed's first checkpoint in full, every checkpoint side by side, or its latest in full; the choice holds from seed to seed

    Keys

    ←→
    Previous or next episode of the run, seed in a seed's tests, checkpoint in a seed's episode; in the strip, its previous or next column
    TabEnter
    Tab reaches the strip; Enter opens the seed or the episode focused
    Esc
    Back: from a seed to where the view was, from an episode opened from Both to its seed
    End
    Latest: follow the episode in progress, while the run is live
    D
    Diagnosis: the nearest episode the teacher diagnosed
    T
    Teacher: the nearest episode the teacher drove
    M
    Move: the frames right before and after the box or bin was moved, side by side; again to go back
    Space
    Pause or resume; new events wait while paused
    Enter
    Teach: in the Teach box, sends what you typed. While you type there, the keys above type text.
