Run

Runs, live first

      Labels
      Live
      Events are arriving (the last within 20 s), or a fine-tune started in the last 30 minutes is still running.
      Recorded
      From the run's saved files; nothing new is arriving for it.
      Disconnected
      The page lost the run's event stream and is retrying; nothing shown is live until it returns.
      Paused
      Space is holding the view; new events wait until it resumes.
      Placeholder
      The run is on FakeSim, the stand-in simulator, or names no simulator. A panel with nothing to show says so in words.
      Configured
      Set in the code, not measured.
      Not started
      A Teach the task generator refused, or a task the loop does not train on yet; nothing ran. The run says why.
      StudentTeacher
      Who chose a skill: blue for the student, teal for the teacher. Green and red mark only success and failure.
      Rail
      One mark per episode: tall for the teacher, short for the student; filled when it succeeded or was accepted for training, hollow when it failed or was rejected, half-filled while it runs. The outlined mark is the episode shown.

      Keys

      ←→
      Previous or next episode
      End
      Now: the episode in progress, while the run is live
      D
      Diagnosis: the nearest episode the teacher diagnosed
      T
      Teacher: the nearest episode the teacher drove
      M
      Move: the frames right before and after the box or bin was moved, side by side; again to go back
      Space
      Pause or resume; new events wait while paused
      Enter
      Teach: in the Teach box, sends what you typed. While you type there, the keys above type text.
